# 1. Two Sum

- **题目 : [1. 两数之和](https://leetcode.cn/problems/two-sum/)**

> 难度: 简单
>
> 标签: 哈希

## 解法一

### 暴力双层循环

- 提示里面提到**只会存在一个有效答案**, 所以数组中一定有**两数之和**为`target`

既然两数相加为`target`, 那么说明用`target`减去其中一个数`num1`后,可以在数组`nums`中找到另一个数`num2`.

例如: 

```java
nums = [2, 7, 11, 15] , target = 9 
num1 = 2 , target - num1 = 7
nums[1] = 7
```

**AC代码**

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int arrLen = nums.length;
        for(int i = 0; i < arrLen; i++) {
            int num1 = nums[i];
            int num2 = target - num1;
            for(int j = i + 1; j < arrLen; j++) {
                if(num2 == nums[j]) {
                    //返回答案
                    return new int[]{i, j};
                }
            }
        }
        //防止代码报错,代码不会运行到这里
        return new int[]{};
    }
}
```

- **暴力双层循环时间复杂度为 O (n²)**

- **空间复杂度为 O(1)**

## 解法二

### 哈希表简化

- 思路同上, 用`target`减去其中一个数`num1`后,可以在数组`nums`中找到另一个数`num2`.
- 只不过我们可以用**HashMap**来存储遍历过的`num`, 所以便只需要遍历一次即可

**AC代码**

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int arrLen = nums.length;
        // key: num     value: index
        HashMap<Integer, Integer> map = new HashMap<>();
        for(int i = 0; i < arrLen; i++) {
            int num1 = nums[i];
            int num2 = target - num1;
            // 判断哈希表中是否存在num2这个key
            if(map.containsKey(num2)) {
                // 找到就返回答案
                return new int[]{map.get(num2), i};
            }
            //没找到就把当前元素put进map里面
            map.put(num1, i);
        }
        //防止代码报错,代码不会运行到这里
        return new int[]{};
    }
}
```

- **时间复杂度 O (n)**

只遍历数组一遍，HashMap 的`containsKey`、`put` 查询添加都是 O (1)

- **空间复杂度 O (n)**

最坏情况下，所有元素存入哈希表，占用 n 个存储空间，拿空间换时间。

> 如果忘记或者不清楚关于map相关的方法,可以看java刷题常用方法

## 补充知识点

- **关于创建数组**

1. `int[] a = {1,2,3};` ✅合法，变量初始化
2. `int[] a; a={1,2,3};` ❌非法，分开写不行
3. `return new int[]{1,2};` ✅合法，匿名数组
