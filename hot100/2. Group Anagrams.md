# 2.Group Anagrams

- **题目: [49. 字母异位词分组](https://leetcode.cn/problems/group-anagrams/)**

> 难度: 中等
>
> 标签: 哈希

## 解法一

### 排序原始字符串

- 对于字符串`"ate", "eat", "tea"`,将他们转为**字符数组**并进行**排序**后,再转为字符串结果都是相同的.

例如:

```java
"ate" --> ['a', 't', 'e']  sort--> ['a', 'e', 't'] --> "aet"
"eat" --> ['e', 'a', 't']  sort--> ['a', 'e', 't'] --> "aet"
"tea" --> ['t', 'e', 'a']  sort--> ['a', 'e', 't'] --> "aet"
```

- 因此我们可以用map去存储. 
- 将他们排序后的结果字符串作为key, 将存放原始字符串的集合作为value

**AC代码**

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> ret = new ArrayList<>();
        
        //key: 排序后的字符串  value: 存放属于该字符串分组的原始字符串
        Map<String, List<String>> map = new HashMap<>();

        //增强for遍历strs数组
        for(String str : strs) {
            //把字符串转换为字符数组才可以进行排序
            char[] arr = str.toCharArray();
            //排序
            Arrays.sort(arr);
            //将排序好的字符数组转为字符串并作为key加进map里面
            String key = new String(arr);

            //如果map里面不存在这个key
            if(!map.containsKey(key)) {
                //新建一个分组
                List<String> ans = new ArrayList<>();
                //将这个新分组put进map里面
                map.put(key, ans);
                //再将这个新分组add进ret里面
                ret.add(ans);
            }
            //此时该分组一定已经存在,取出分组列表,把当前原始字符串添加进去
            map.get(key).add(str);
        }
        return ret;
    }
}
```

> n：字符串数组 `strs` 的元素总个数
>
> k：**单个字符串的最大长度**（最长单词多少个字母）

- **总时间复杂度：O(n·k·log k)**

- **空间复杂度：O(n·k)**

## 解法二

### 计数

> **提示：**
>
> - `1 <= strs.length <= 104`
> - `0 <= strs[i].length <= 100`
> - `strs[i]` 仅包含小写字母

- 可以看到, 提示里面说明了只包含小写字母,所以也可以用一个数组去计数每个字符出现的次数
- 本质思路和排序差不多,只不过这里计数完后再拼成key

**AC代码**

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> ret = new ArrayList<>();

        //key: 排序后的字符串  value: 存放属于该字符串分组的原始字符串
        Map<String, List<String>> map = new HashMap<>();

        //增强for遍历strs数组
        for(String str : strs) {
            //创建int数组存放26个字母对应出现过的次数,初始全为0
            int[] count = new int[26];
            
            //将当前遍历的初始字符串转为char数组
            //然后遍历这个char数组的每个元素
            for(char ch : str.toCharArray()) {
                //用ch - 'a'将每个字符都转换了int数组的下标
                count[ch - 'a']++;
            }

            //把计数数组拼接成唯一key，例如"1,2,0,11,6,0...1"
            StringBuilder sb = new StringBuilder();
            for(int num : count) {
                sb.append(num).append(",");
            }
            String key = sb.toString();

            //如果map里面不存在这个key
            if(!map.containsKey(key)) {
                //新建一个分组
                List<String> ans = new ArrayList<>();
                //将这个新分组put进map里面
                map.put(key, ans);
                //再将这个新分组add进ret里面
                ret.add(ans);
            }
            //此时该分组一定已经存在,取出分组列表,把当前原始字符串添加进去
            map.get(key).add(str);
        } 
        return ret;
    }   
}
```

> n：字符串数组 `strs` 的元素总个数
>
> k：**单个字符串的最大长度**（最长单词多少个字母）

- **时间复杂度：O(n·k)**

- **空间复杂度：O(n·k)**
